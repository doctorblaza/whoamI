# whoamI

第一人称恐怖悬疑网页文字冒险游戏。原文一字不改，纯线性剧情；选项仅为形式，不影响剧情。

Play: https://doctorblaza.github.io/whoamI/

## 本地预览

用任意静态服务器打开本目录，例如：

```bash
python3 -m http.server 8080
```

手机浏览器访问电脑 IP 的 8080 端口即可试玩。

## 目录

- `index.html` — 游戏页面
- `css/style.css` — 样式
- `js/engine.js` — 文字冒险引擎（线性）
- `js/story.js` — 剧情脚本（原文）
- `js/music.js` — 配乐管理
- `assets/` — 插画与配乐
